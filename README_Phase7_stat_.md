## 1. 개요

Phase 7 통계 탐지는 Phase 1~6에서 산출한 기준선(IRF 피크 시차, 전이탄력성, ECT)을 기반으로, 가격 전달 경로에서 3종 이상 패턴을 탐지하는 단계이다. ML 앙상블 탐지(Phase 7-ML)는 별도 문서에서 다룬다.

### 3종 패턴 적용 범위

| 구간     | 패턴 1 | 패턴 2 | 패턴 3 | 비대칭 검정 | 구간 수 |
| -------- | :----: | :----: | :----: | :---------: | ------- |
| A        |   O    |   O    |   -    |      O      | 10      |
| B        |   O    |   O    |   O    |      O      | 10      |

| D        |   O    |   -    |   -    |      -      | 3       |
| D'       |   O    |   -    |   -    |      -      | 7       |
| **합계** | **33** | **20** | **10** |   **20**    | **33**  |

## 2. 코드 구조

```
src/preprocessing/Phase7/
    phase7_common.py       공통 모듈 (데이터 로딩, 전이율 산출, SubperiodResolver)
    phase7_pattern1.py     패턴 1 탐지 (방향 역전 + 시차 이탈)
    phase7_pattern2.py     패턴 2 탐지 (Z-score+IQR + 비대칭 검정)
    phase7_pattern3.py     패턴 3 탐지 (스프레드 누적 확대)
    phase7_integrate.py    통합 (phase7_summary + stat_timeseries 생성)
```

반드시 pattern1 -> pattern2 -> pattern3 -> integrate 순서로 실행한다.

## 4. 파라미터 및 설계 결정

### 4.1 파라미터 총괄

| 파라미터                         | 값        | 용도                |
| -------------------------------- | --------- | ------------------- |
| ROLLING_WINDOW                   | 48개월    | 패턴 2 롤링 윈도우  |
| ZSCORE_ALERT                     | 2.5       | Z-score 경보        |
| IQR_MULTIPLIER                   | 1.5       | Tukey 표준          |
| STABILITY_THRESHOLD              | 3%        | 국제가 안정 구간    |
| PATTERN3_N_VALUES                | [2, 3, 6] | 스프레드 연속 개월  |
| TRANSMISSION_RATE_MIN_UPSTREAM   | 0.5%      | 전이율 분모 필터    |
| DIRECTION_REVERSAL_MIN_MAGNITUDE | 1.0%      | 방향 역전 최소 크기 |

### 4.2 설계 결정

(1) 전이율 분모 처리: 상류 < 0.5%이면 NaN. 미적용 시 전이율 절대최대 563, 적용 후 19.77. A/B 구간 평균 10.1% 제외.

(2) 구조 변화 시 기준선: 하위 기간별 적용. SubperiodResolver가 날짜를 subperiod에 매핑.

(3) 롤링 윈도우 리셋: 안 함. 전체 기간 연속 운영.

(4) 시차 이탈 무반응 판정: (정상 시차+1)개월 내 같은 방향 반응 한 번이라도 있으면 반응함.

(5) 방향 역전 크기: 양쪽 >= 1.0%. 미적용 시 44.4% 과다 탐지, 적용 후 17.7%.

(6) 스프레드 확대: 같은 부호 + 절대값 확대. A안(절대값만) 대비 차이 10건(7%).

(7) Z-score + IQR 일치율 100%: 모수적/비모수적 기준 동일 결과.

(8) stat_timeseries: Phase 7에서 생성. DB 직접 적재 형태.
